# About

I like Scotch. (Scotch, Scotch, Scotch.) This is just a place for me to write about the whiskies I've tried, keep track of those experiences, and hopefully share those experiences with others. That's about it.

**RATINGS:**

Ultimately, I don't care for "rating" whiskies, but rather prefer to talk about the experience of drinking the whisky. However, I can appreciate a "quantified" summary of the overall impression the whisky left on the drinker. I find the 100-point and 10-point scales many use to be pretty confusing, inconsistent, and more nuanced than is immediately helpful. It's not a scientific measurement. At the same time, it's inherently trivializing.

As such, I've chosen to use a very trivial system. *The rough but detailed enough pretty self explanatory 5-star system.* Do we really need to get more complicated than that? (I was using a 10-point scale previously and plan to go back and change those.)
